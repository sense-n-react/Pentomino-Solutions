# Pentomino Solutions

This repository contains pentomino tiling solutions for various board sizes.

Each solution is represented as ASCII art in Markdown, allowing the boards to be viewed directly on GitHub without any additional tools.

A color-coded HTML version is also available: **[Pentomino Solutions (HTML)](https://sense-n-react.github.io/PentominoSolutions/)**. It displays correctly on smartphones as well.

## Viewing Solutions

Each board size has its own directory containing an index and multiple Markdown files.

Solutions are divided into smaller files to keep individual pages manageable and make browsing easier on GitHub. Open the index in each directory to browse the solutions by number.

## Symmetry

Solutions are listed with symmetry-equivalent arrangements eliminated. Arrangements that differ only by symmetry are counted as a single solution.

## Solution Format

Each solution is displayed as ASCII art using a fixed-width font. 
For 3D boards, each solution is displayed as a sequence of 2D layers, with each layer represented using ASCII art.

## About This Repository

This repository aims to collect and share pentomino tiling solutions in a simple, readable format that is easy to browse, compare, and use for educational purposes.
